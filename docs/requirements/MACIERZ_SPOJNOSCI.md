# RoomBook — macierz spójności

Podstawa: [specyfikacja 1.0](../SPECYFIKACJA_ROOMBOOK.md), rozdziały 7, 10–12. Macierz wiąże [wymagania](WYMAGANIA.md) z [formalnymi UC](../use-cases/PRZYPADKI_UZYCIA.md) i [diagramem UC](../use-cases/diagram-przypadkow-uzycia.puml).

**AD-01…AD-03 istnieją jako źródła PlantUML i eksporty SVG; SD-01…03, klasy, ERD i szkic Prisma istnieją jako projekty etapu 04. UI-01…07 istnieją jako [makiety i prezentacyjny frontend etapu 05](../ui/MAKIETY.md). Etap 06 wdrożył cztery modele, migrację, seed oraz auth. Etap 07 wdrożył backend sal/dostępności i rezerwacji z testami TC-05…14; etap 08 dodaje backend administracji i TC-15…21. UI nadal nie korzysta z API.** Identyfikatory TC-01…TC-26 zachowują znaczenie z rozdziału 11 specyfikacji. Wyniki wykonanych kontroli podano osobno poniżej; docelowa tabela WF pozostaje planem również dla UI. Dodatkowe powiązania TC-13/14/15 z WF-15 dotyczą prywatności i autoryzacji.
