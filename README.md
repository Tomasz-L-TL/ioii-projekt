# RoomBook — system rezerwacji sal na uczelni

RoomBook to projekt aplikacji internetowej ułatwiającej studentom rezerwowanie sal do nauki i spotkań na uczelni. System ma umożliwiać przeglądanie dostępnych sal i terminów, tworzenie rezerwacji oraz anulowanie własnych rezerwacji. Administrator będzie mógł zarządzać salami, blokować wybrane terminy i przeglądać wszystkie rezerwacje.

Projekt powstaje w ramach przedmiotu **Inżynieria Oprogramowania II**. Obejmuje analizę wymagań, przygotowanie dokumentacji i diagramów projektowych, implementację aplikacji oraz jej testowanie. Celem jest stworzenie niewielkiego, spójnego systemu, który zapobiega konfliktom rezerwacji i pozwala w prosty sposób zarządzać dostępnością sal.
